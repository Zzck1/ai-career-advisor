# 大学生 AI 生涯规划顾问

面向中国大陆在校大学生及应届毕业生的 Codex Skill。它通过“基础信息表＋核心问题库＋动态追问”，帮助学生认识自己、比较发展路线，并形成有依据的建议和行动计划。

支持比较就业、国内升学、海外升学、海外就业、考公和创业等方向。咨询中每轮只提出一个关键问题，并明确区分学生提供的依据、联网核实的事实、AI 的推断和尚未确定的条件。

## 使用方式

将 `outputs/ai-career-advisor` 文件夹复制到 Codex 的 Skills 目录，然后使用：

> 请使用 $ai-career-advisor 帮我规划大学毕业后的发展方向，先收集必要的基本信息，之后每次只问一个关键问题。

仓库同时提供：

- `outputs/ai-career-advisor.zip`：可分发的 Skill 压缩包。
- `outputs/大学生AI生涯规划顾问-可复制指令.md`：适用于支持长指令的其他 AI 平台；联网核实仍依赖平台本身具备联网能力。

## 主要文件

- `SKILL.md`：咨询流程、核心规则和输出要求。
- `references/question-bank.md`：九类核心问题与各路线分支问题。
- `references/decision-rules.md`：证据、联网核实和路线判断规则。
- `references/deliverables.md`：精简决策卡与完整规划报告模板。

## 设计原则

- 已经回答的信息不重复询问，学生可以回答“不知道”或“暂不提供”。
- 初步探索的 5—8 个问题是体验目标，不是硬性题数。
- 不用虚构的适合度分数或成功率代替证据。
- 重要条件发生变化时，路线建议和行动计划随之更新。
- 信息不足或关键事实尚未核实时，明确保留暂定结论。
