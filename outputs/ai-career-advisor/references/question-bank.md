# 核心问题库与动态追问

这是供顾问选择的题库，不是发给学生的问卷。基础信息之后每轮仅选择一个问题；表格同一单元格中的多个示例是不同轮次的备选问法。已回答的问题跳过，没有决策价值的方面不必覆盖。

## 九个探索方面

| 方面 | 可选问题（每次选一） | 判断用途 |
| --- | --- | --- |
| 当前困惑与决策动机 | 最近发生了什么，让你开始考虑生涯规划？／如果这次只能解决一件事，你最希望解决什么？ | 真正要解决的问题、触发事件和期限 |
| 兴趣与投入感 | 过去一年，什么事情让你愿意主动花时间？／在这件事里，你喜欢的是过程、获得认可，还是最后的成果？ | 兴趣落在什么具体活动，不把消费内容等同于从业兴趣 |
| 能力与经历证据 | 讲一件你做得比较好的事，你具体负责什么？／这件事收到了什么具体反馈？ | 行为、个人贡献、结果是否支持自评 |
| 学习与工作方式 | 面对没有标准答案的任务，你通常怎样推进？／长期备考、研究和实际项目中，哪种经历你更能持续投入？ | 对不同任务方式的适应与真实体验 |
| 价值观与取舍 | 收入、稳定、成长、自由、意义、生活时间，你最重视哪三项？／当你刚才提到的这两项冲突时，你愿意暂时让步哪一项？ | 学生自己的比较标准及冲突排序 |
| 现实条件与资源 | 你能承受多长时间没有稳定收入？／可投入的预算大致在哪个区间？／目前有哪些已经确认可用的支持？ | 可行性、现金流与资源是否落实 |
| 地域与生活偏好 | 你愿意在哪些地区学习或工作？／对长期异地、海外生活或频繁出差，你最不能接受的是什么？ | 生活方式、地域底线与可协商部分 |
| 风险与备选安排 | 如果第一选择没有成功，你可以接受什么结果？／你希望在什么节点重新评估这条路线？ | 可承受代价、备选方案与退出条件 |
| 执行与准备状态 | 你已经为这个方向做过什么？／每周实际能投入多少时间？／过去类似计划中，什么最影响你能否坚持？ | 当前起点、容量与执行障碍 |

同一经历可支持多个方面，但分别标明结论及证据强弱。追问结果和反馈不是审问；不要求学生提交证书或他人隐私证明日常陈述。

## 动态追问示例

| 学生回答 | 下一轮可问 | 记录与判断限制 |
| --- | --- | --- |
| 我不知道自己喜欢什么 | 最近一周，哪件事你做起来相对不排斥，甚至愿意多做一点？ | 先建立活动线索，不要求宏大理想 |
| 我沟通能力很强 | 能举一次你通过沟通解决分歧的具体经历吗？ | 具体行为出现前，只记为能力自评 |
| 我想考研，因为大家都考 | 如果身边的人都不考研，你还会考虑吗？ | 接受社会影响存在，继续理解个人动机，不羞辱从众 |
| 我想赚得多，也要轻松稳定 | 如果这些条件暂时不能同时满足，你目前最愿意让步的是哪一项？ | 记录取舍，不承诺不存在代价的路线 |
| 我没有实习或项目经历 | 课程作业、社团、兼职或生活中，有没有一件你独立负责并完成的事？ | 没有正式经历不等于没有能力 |
| 我想留学，但不知道为什么 | 留学最吸引你的，是学习内容、生活体验、未来工作机会，还是其他原因？ | 区分体验诉求与学业、工作目标 |
| 预算暂时不方便说 | 你是否愿意只说明，需要全额资助才能考虑，还是能承担一部分费用？ | 只在预算确实改变建议时这样问；若仍不愿回答便跳过，采用条件分支 |
| 仍想不出具体经历 | 如果只能体验一周，你更愿意尝试整理资料回答一个问题，还是做出一个可用的小作品？ | 标记为情境选择，不能当作能力证据；选项应贴合当前候选方向 |

没有经历时可建议微型体验：一次真实任务、一个课程延伸项目、一次从业者访谈或短时研究体验。明确要观察的行为和决策问题，不能以一次体验推断终身适合与否。

## 候选方向分支

分支确定后只补关键缺口；以下每一问仍单独成轮。

| 方向 | 可选问题 | 后续需核实的条件 |
| --- | --- | --- |
| 就业 | 你希望尽快工作主要是为了什么？／目前有哪些经历能证明你能完成实际任务？／你能接受怎样的工作起点？ | 具体岗位任务、学历专业要求、招聘时间和地点；薪资要区分岗位、地区、口径与时间 |
| 国内升学 | 继续读书希望解决什么问题？／你对研究训练有什么实际体验？／如果升学结果不理想，备选安排是什么？ | 当年院校与项目要求、专业限制、推免或统考路径、节点、费用；不能仅凭学校标签判断资格 |
| 海外升学 | 出国学习对你最重要的价值是什么？／语言准备目前到什么程度？／你可承担的总预算大致是什么范围？／毕业后倾向回国、留在当地，还是尚未确定？ | 当期项目录取与语言要求、申请轮次、费用及生活成本、奖助资格；毕业后工作路径另行核实 |
| 海外就业 | 你倾向直接求职还是先升学？／你对目标地区工作的了解主要来自哪里？／目前有哪些语言或实践经历与目标工作相关？ | 岗位要求、语言、资格认证、合法工作资格与雇主支持条件，按地区和适用对象核实 |
| 考公 | 吸引你的是具体工作内容、稳定性、地域，还是家人的期待？／你愿意投入多少准备时间？／未成功时怎样调整？ | 当期公告及具体职位表中的专业、学历、身份、年龄等条件和节点；仅在确有必要时询问相关信息 |
| 创业 | 你想解决谁的什么问题？／是否接触过真实用户并得到反馈？／你能承受多长时间的不确定收入？／可接受的试验投入上限是多少？ | 需求证据、成本与收入假设、资源承诺、必要资质；先设计可撤回的需求验证，不能从兴趣直接跳到全职投入 |

海外是地域维度；就业、升学等是路径维度。必要时比较“国内就业”“国内升学”“海外升学后再求职”等实际组合，并说明后续转段需要的条件。
